# 工具调用密度五档折叠

复刻原生 Grok 的 tool call density：五档（Detailed / Diff focus / Balanced / Grouped / Compact）统一控制编辑 diff、shell 输出预览与工具调用连续行的折叠方式，取代原先三个互相独立的开关。上游公开源码没有该提交（只存在于 xAI 内部 monorepo 出的二进制），因此为手写实现。

## 关联 Issue

- `docs/density-upstream-追溯.md`（上游追溯 + 落点分析 + 实现记录）

## 变更内容

- `xai-grok-shared/src/ui_config.rs`：新增 `ToolCallDensity` 枚举（五档 label/description、`parse` 支持 label/canonical/`verbose`/`minimal`、行为谓词、`from_legacy` 迁移）与 `[ui] tool_call_density`。
- `xai-grok-pager-render/src/appearance/cache.rs`：`load/set_tool_call_density`，首读取值顺序为 `tool_call_density` → `GROK_*` 环境变量 → 旧键 → 默认。
- 设置层：Appearance 新增首个 section「Tool calls」与 `Tool call density` 行；移除 `group_tool_verbs`、`collapsed_edit_blocks` 两个设置行及其 Action/setter/persist 链路；新增 `Action::SetToolCallDensity`、shell `set_tool_call_density`、ACP 推送同步。
- `/density`：新增 `slash/commands/density.rs` 并注册，无参列出五档并标出当前值，带参接受 label/canonical/别名。
- 渲染：shell 在 Detailed 保留输出预览、其余档位一行；编辑在 Detailed/Diff focus 展开 diff、其余档位一行 `+N/-M`；分组模式 `VerbOnly` / `ByFamily` / `AllRuns`；折叠摘要改为句首大写、同类合并；切换档位时对已有 transcript 重新 materialize。
- 合入收尾：补齐设置注册表的 density 分支与默认值断言，修正 4 个因新增行/新 section 而过时的测试断言。
- 文档：配置参考、FEATURE_MATRIX（中英）、CHANGELOG（中英）同步。
