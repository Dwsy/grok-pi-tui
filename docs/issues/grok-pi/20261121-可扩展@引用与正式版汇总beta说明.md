# `@` 对象引用与正式版汇总 beta 说明

## 约束

- 本地不运行 Cargo（`AGENTS.md` 硬规则）。本批改动的 Rust 部分只做静态审查，编译由 CI 或用户显式授权的本地构建验证。
- 提交按主题分组：`@` 引用功能、仓库文档（AGENTS.md / RSI 技能）、发布说明与 CI。
- `pi-main` 子模块指针变化不纳入本次提交（`AGENTS.md` 要求显式授权）。
- 正式版 release notes 必须包含同核心版本的全部 beta 段落；beta tag 仍只输出自身段落。

## 验收清单

- [x] `scripts/extract-changelog-section.py` 的版本排序改为完整 SemVer（含 prerelease 标识符比较）
- [x] 新增 `--with-prereleases`：正式版汇总同 `X.Y.Z` 的全部 `X.Y.Z-beta.N`，自身段落居首
- [x] 正式版自身段落缺失时 `--strict` 失败（不拿 beta 段顶替）
- [x] `release.yml` 的 `validate-changelog` 与发布作业对非 beta tag 均加 `--with-prereleases`
- [x] 提取器 `--self-test` 覆盖 beta 排序、beta 汇总、缺段失败与既有资产断言
- [x] `CHANGELOG.MD` / `docs/CHANGELOG.zh-CN.md` 补齐 Unreleased，并回填 beta.5 / beta.6
- [x] `docs/FEATURE_MATRIX{,.zh-CN}.md` 增补 `@` 对象引用
- [x] `docs/usage/release.md` 记录新参数与排序保证
- [ ] 推送 `main` 后由 CI 验证编译

## 风险

- `mentions.rs`、`pi_adapter/tools.rs`、`acp_handler/mod.rs` 的改动未经本地编译；静态审查确认了导入、`send_ext_notification` 签名、`PiSessionInfo` 字段与 `spawn_blocking` 用法，但仍需 CI 兜底。
- `@session` 依赖 PSM 的 `sessions.db` 结构；表或列变更时 ts 侧会静默回落到 adapter 的 `rusqlite` 路径，行为退化为最近 50 条而无报错。
