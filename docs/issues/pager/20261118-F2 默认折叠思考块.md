# F2 默认折叠思考块

## 目标

在 F2 设置面板（Appearance → Thinking）新增一个独立开关 **Collapse thinking blocks**，默认关闭。

开启后，思考块在输出过程中不再流式刷新正文，只显示一行 `Thinking…` 标题；本轮结束后仍是折叠态，用户可用 `Ctrl+E` 展开全部思考块查看完整正文。

## 背景

现状（`show_thinking_blocks`，默认开）：

- 思考块在流式输出期间以 `DisplayMode::Truncated` 渲染，每来一个 delta 就重排一次正文（`ThinkingBlock::default_display_mode()` → `Truncated`）。
- 思考结束后 `finished_display_mode()` → `Collapsed`，正文折叠成 `Thought for Xs` 一行。
- `Ctrl+E`（`Action::ExpandAllThinking`）在全部思考块间切换 `Expanded` / `Collapsed`，并把结果写入 `ScrollbackState::thinking_display_mode` 粘性状态。

问题：`Truncated` 态在流式期间反复重排正文，终端里表现为思考文字不断跳动、行高抖动。

## 边界

| 事项 | 归属 |
|---|---|
| 折叠态渲染 | 复用既有 `DisplayMode::Collapsed` 路径（`ThinkingBlock::render_collapsed`） |
| 展开入口 | 复用既有 `Ctrl+E` → `ScrollbackState::expand_all_thinking` |
| 思考正文存储 | 不变，`ThinkingBlock::content` 仍完整保留 delta |
| `show_thinking_blocks` | 不动。它管"思考块是否出现"，本开关管"出现后是否流式" |
| minimal 模式 | 不动，minimal 有自己的 `minimal_collapse_thinking`（pager.toml `[terminal]`） |
| `Ctrl+E` 展开后的正文 | 完整可读，本开关只影响默认态与流式行为 |

## 实现

新增 Shell-owned 设置 `collapse_thinking_blocks`（`[ui].collapse_thinking_blocks`，默认 `false`）：

1. `xai-grok-shared/src/ui_config.rs`：`UiConfig` 新增 `collapse_thinking_blocks: Option<bool>`，`Default` impl 补 `None`。
2. `xai-grok-pager-render/src/appearance/cache.rs`：新增 `COLLAPSE_THINKING_BLOCKS_DEFAULT = false` + thread-local cache + `load_/set_`。
3. `xai-grok-shell/src/util/config/resolve/ui.rs`：`resolve_collapse_thinking_blocks`（requirements > env > user > managed > remote > default）。
4. `xai-grok-shell/src/util/config/settings_writes.rs`：`set_collapse_thinking_blocks` 落盘。
5. `xai-grok-pager/src/app/event_loop.rs`：启动时 resolve 后灌 cache。
6. `xai-grok-pager/src/settings/defs.rs`：`SettingMeta`（Appearance / Shell / Bool）。**必须放在 `respect_manual_folds` 之后**——`settings_e2e.rs` 断言 `show_thinking_blocks` 紧邻 `respect_manual_folds` 之上，插在中间会破测试。
7. `xai-grok-pager/src/settings/layout.rs`：`section_for` 归入 `"Thinking"` 分区。
8. `xai-grok-pager/src/settings/registry.rs`：`current_value_for` 读 cache；`defaults_match_ui_config_default` 补 match 分支（该 match 穷尽，漏加编译不过）。
9. `xai-grok-pager/src/app/actions.rs` + `dispatch/router.rs` + `dispatch/settings/setters.rs` + `dispatch/settings/ui.rs`：`SetCollapseThinkingBlocks(bool)` 全链路。
10. `xai-grok-pager/src/app/effects/helpers.rs`：`persist_setting` 分支。
11. `xai-grok-pager/src/views/pi_settings/actions.rs` + `views/settings_modal/state.rs`：key → Action 映射（漏加不报错，但按下去没反应）。
12. 渲染：`ThinkingBlock::default_display_mode()` 在开关打开时返回 `Collapsed`（而非 `Truncated`），使新思考块一进入 scrollback 就是折叠态，不再流式重排。

开关运行时切换：复用 `apply_codemode_expanded_by_default_flip` 的模式，给 scrollback 加 `apply_collapse_thinking_blocks_flip`，把"仍处于默认态"的思考块在 `Truncated` / `Collapsed` 间重物化；用户手动折叠过的（`display_mode_pinned`）不动。

## 验证

```bash
./scripts/cargo-shared.sh check -p xai-grok-pager-bin --bin grok-pi
./scripts/cargo-shared.sh test -p xai-grok-pager
./scripts/cargo-shared.sh test -p xai-grok-pager --test settings_e2e
```

`settings_e2e.rs` 的 `ALL_SETTINGS_EXERCISED` 契约要求每个 `SettingMeta` 都要有条目 + 键盘 + 鼠标用例。

## 接缝

不新增 Pager 原生接缝；复用既有 `DisplayMode::Collapsed` 渲染路径与 `Ctrl+E` 动作。
